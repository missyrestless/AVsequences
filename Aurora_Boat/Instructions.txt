AVsitter Sequence for the Mesh Shop Aurora Boat
────────────────────────────────────────────────

The Mesh Shop Aurora is one of the finest boats in Second Life, a 33 foot open powerboat with a top speed of 50 knots. However, the TMS Aurora is delivered with 'AVsitter1' scripts. In March of 2014 'AVsitter2' was released. This newer version of the pose system provides many enhancements, bug fixes, and features as well as stability and optimization improvements. Of particular importance to sailors, 'AVsitter2' improves stability of seated passengers across region crossings.

This repository contains the 'AVpos' notecard and the necessary 'AVsitter2' scripts to upgrade the TMS Aurora from 'AVsitter1' to 'AVsitter2'. In addition, and optionally, the repository also contains an '[AV]sequence_settings' notecard for use with the 'AVsitter2' plugin '[AV]sequence' to provide animation sequences for the TMS Aurora dialog menus.

**[Note:]** 'AVsitter2' was first released in March of 2014. These older 'AVsitter1' scripts continue to work and an upgrade to 'AVsitter2' is not necessary unless you wish to take advantage of the new features, bug fixes, and stability improvements. The Mesh Shop Aurora and many other popular boats in Second Life are delivered by default with 'AVsitter1' scripts that were last updated prior to 2014. The Truth &amp; Beauty Lab provides enhanced and optimized 'AVsitter2' scripts that can easily replace the archaic 'AVsitter1' scripts in your boats.

AVsitter2 Upgrade Steps
──────────────────────────

To upgrade a Mesh Shop Aurora to 'AVsitter2':

- Right click the boat and select 'Edit'
- Select the Contents tab in the Edit window
- Delete the AVsitter1 scripts
  - The AVsitter1 scripts are 'AVsit', 'AVsit 1', 'AVsit 2', and 'AVsit 3'
  - Delete the AVsitter1 scripts from the Contents tab of the Edit window
- Add the AVsitter2 scripts to the Contents tab of the Edit window
  - Make copies of both the '[AV]sitA' and '[AV]sitB' scripts and name them:
    - '[AV]sitA'
    - '[AV]sitA 1'
    - '[AV]sitA 2'
    - '[AV]sitA 3'
    - '[AV]sitB'
    - '[AV]sitB 1'
    - '[AV]sitB 2'
    - '[AV]sitB 3'
  - Drag and drop these 8 '[AV]sit*' scripts from your inventory into the Contents tab
- Replace the 'AVpos' notecard in the Contents tab with the 'AVpos' notecard found in this folder
- Close the 'Edit' window
- Right click the boat and select 'More' -> 'More' -> 'Scripts' -> 'Reset Scripts'
- Wait for the scripts to reset (this takes a few minutes)

NOTE: If you are going to add new poses, positions, or props then also drag and drop the '[AV]adjuster' script from your inventory into the Contents tab of the Edit window.

Adding Sequences
────────────────────

Once your boat has been upgraded to 'AVsitter2' you can add animation and pose sequences to automate transition through a series of poses and animations. This is optional and not needed for an 'AVsitter2' upgrade. Note that adding sequences increases the script load on the boat and has a slight impact on region crossings. If all you want is increased stability and resilience when crossing region boundaries then you can skip the addition of animation and pose sequences.

Sequence Menus
───────────────────

Sequences are configured for the following menus:

- Solo Menus (all 4 sitters)
- Cuddle Menus (first 2 sitters)
- Foreplay Menus (first 2 sitters)
- Hardcore Menus (first 2 sitters)
- Low n Slow Menus (first 2 sitters)
- System Menus (1st sitter only)

Sequences Setup
──────────────────

To configure a Mesh Shop Aurora Boat with AVsitter sequences:

- Right click the boat and select 'Edit'
- Select the Contents tab in the Edit window
- Copy the '[AV]sequence_settings' notecard into the Contents tab
- Copy the '[AV]sequence' plugin script into the Contents tab
- Replace the 'AVpos' notecard in the Contents tab with the 'AVpos-sequences' notecard found in this folder
- Close the 'Edit' window
- Right click the boat and select 'More' -> 'More' -> 'Scripts' -> 'Reset Scripts'
- Wait for the scripts to reset (this takes a few minutes)

Sit on the boat and click one of the sequence buttons, for example: '►SOLO' or '►CUDDLE'.

Sequence menu buttons are of the form '►...'. Click this menu entry and your avatar will cycle through all the animations in that submenu.

Cycle times are currently set to 90 seconds with menu arrows to step to the next animation, previous animation, or pause animation sequencing.

Auto Play Sequence
──────────────────

If you wish to automatically play a sequence when an avatar sits on the boat then drag and drop the 'autoplay' script into the Contents of the boat.

The 'autoplay' script detects the gender of the sitter and plays the appropriate sequence. In addition, it detects the number of sitters currently on the object and plays the cuddles animation sequence if 2 sitters are seated.
